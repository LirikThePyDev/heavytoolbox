NMAP SETUP GUIDE
================
Official Nmap for Windows is distributed as an installer.
1. Visit https://nmap.org/download.html
2. Download the latest stable Windows installer (e.g., nmap-setup.exe).
3. Install it and ensure 'nmap' and 'npcap' are installed.
4. To make this portable workspace work:
   - Copy the contents of the Nmap installation directory (usually C:\Program Files (x86)\Nmap)
   - Paste them into C:\HeavyToolbox\tools\nmap
